# Waiting Room App – Flutter Workshop 2

Une application Flutter de salle d'attente développée dans le cadre du **Workshop 2**.

## 📄 Documentation

Le compte rendu complet du Workshop 2 est disponible dans le dossier [`docs/`](docs/Compte_rendu_Workshop2.pdf).

## 🚀 Démarrage rapide

### Prérequis

- Flutter SDK installé ([flutter.dev](https://flutter.dev))
- Un émulateur Android/iOS ou un appareil physique

### Installation

```bash
# Cloner le repository
git clone https://github.com/AmenallahBensalem/TP2_flutter.git
cd TP2_flutter

# Installer les dépendances
flutter pub get

# Lancer l'application
flutter run
```

## 🛠️ Technologies utilisées

- **Flutter** – Framework UI multiplateforme
- **Dart** – Langage de programmation
